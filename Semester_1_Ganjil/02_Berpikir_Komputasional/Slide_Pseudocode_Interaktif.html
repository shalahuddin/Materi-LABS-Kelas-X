Sebelum Menulis

5 Aturan Emas Menulis Pseudocode

  1. Bahasa konsisten — pilih Indonesia atau Inggris, jangan dicampur.
  2. Satu baris = satu perintah — jangan tumpuk banyak aksi di satu baris.
  3. Nama variabel jelas — gunakan totalBelanja, hindari nama abstrak seperti x.
  4. Gunakan Indentasi — geser tulisan ke kanan di dalam blok JIKA atau UNTUK.
  5. Tutup yang dibuka — pastikan ditutup rapi dengan SELESAI JIKA / UNTUK.

Aturan indentasi ini sangat penting karena bahasa Python juga memakainya minggu depan!

Aturan Berhitung

Indeks Manusia vs Indeks Komputer

Daftar siswa: ["Andi", "Bima", "Rina"]

Indeks Manusia (1-Based)

Mulai dari 1

Urutan 1: Andi, Urutan 2: Bima, Urutan 3: Rina.
Ditulis: UNTUK i = 1 SAMPAI 3

Indeks Komputer (0-Based)

Mulai dari 0

Indeks 0: Andi, Indeks 1: Bima, Indeks 2: Rina.
Ditulis: UNTUK i = 0 SAMPAI 2

Komputer dan bahasa Python menghitung dari 0. Memahami ini penting agar kodingmu tidak error minggu depan!

Contoh Kasir Kantin

Logika Kasir Kantin

MULAI
  BACA uang
  JIKA uang >= 15000 MAKA
    TULIS "Ini nasi gorengnya"
  LAINNYA
    TULIS "Uangmu kurang"
  SELESAI JIKA
SELESAI

Bagaimana Logikanya?

  • BACA uang — mengambil input nominal uang.
  • JIKA uang >= 15000 — kondisi minimal harga nasi goreng.
  • TULIS ... — output berupa struk/kata-kata kasir.

Uang dimasukkan Rp20.000 → Syarat terpenuhi → Muncul "Ini nasi gorengnya" ✅

Pencarian Linear

Cek Absen Satu per Satu (Linear Search)

1-Based (Gaya Manusia)

MULAI
  BACA daftar, target
  posisi ← -1
  UNTUK i = 1 SAMPAI jumlahNama
    JIKA daftar[i] = target MAKA
      posisi ← i
    SELESAI JIKA
  SELESAI UNTUK
  TULIS posisi
SELESAI

0-Based (Gaya Komputer / Python)

MULAI
  BACA daftar, target
  posisi ← -1
  UNTUK i = 0 SAMPAI jumlahNama - 1
    JIKA daftar[i] = target MAKA
      posisi ← i
    SELESAI JIKA
  SELESAI UNTUK
  TULIS posisi
SELESAI
Pencarian Binary

Tebak di Tengah (Binary Search)

1-Based (Gaya Manusia)

MULAI
  kiri ← 1; kanan ← jumlahNama
  posisi ← -1
  SELAMA kiri <= kanan
    tengah ← (kiri + kanan) / 2
    JIKA daftar[tengah] = target MAKA
      posisi ← tengah; kiri ← kanan + 1
    LAINNYA JIKA daftar[tengah] < target MAKA
      kiri ← tengah + 1
    LAINNYA
      kanan ← tengah - 1
    SELESAI JIKA
  SELESAI SELAMA
  TULIS posisi
SELESAI

0-Based (Gaya Komputer)

MULAI
  kiri ← 0; kanan ← jumlahNama - 1
  posisi ← -1
  SELAMA kiri <= kanan
    tengah ← (kiri + kanan) / 2
    JIKA daftar[tengah] = target MAKA
      posisi ← tengah; kiri ← kanan + 1
    LAINNYA JIKA daftar[tengah] < target MAKA
      kiri ← tengah + 1
    LAINNYA
      kanan ← tengah - 1
    SELESAI JIKA
  SELESAI SELAMA
  TULIS posisi
SELESAI

Hindari Ini

5 Kesalahan yang Sering Terjadi

🌐

Campur bahasa

Menulis BACA dicampur else/input.

🧱

Blok tidak ditutup

Lupa menulis SELESAI JIKA / UNTUK.

🐍

Menulis kode asli

Menaruh sintaks ribet (seperti titik koma ; atau kurung kurawal {}).

🏷️

Nama tidak jelas

Menggunakan x atau xyz tanpa makna.

🐘

Terlalu panjang

Mencantumkan aksi non-logika seperti "ambil pena di meja".
