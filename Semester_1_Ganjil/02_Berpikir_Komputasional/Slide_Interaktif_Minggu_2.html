Algoritma

Pilih metode mencari: Cek satu-satu (Linear) atau bagi dua (Binary).

Sebelum Mencari

6 Aturan Main Mencari Kata

  1. Target Jelas: Harus tahu pasti kata apa yang dicari.
  2. Normalisasi: Samakan huruf besar/kecil (misal: ubah semua ke huruf besar).
  3. Tentukan Arah: Dari depan ke belakang, dari A ke Z, dsb.
  4. Kriteria Ketemu: Untuk saat ini harus sama persis.
  5. Kapan Berhenti: Berhenti begitu ketemu ATAU jika daftar sudah habis diperiksa.
  6. Hitung Perbandingan: Catat berapa kali kamu mengecek data (efisiensi).
Cara 1

Linear Search (Cek Satu-satu)

Cara mencari paling dasar: periksa dari depan satu per satu sampai ketemu.

  • Data **boleh acak** (tidak perlu diurutkan).
  • Sangat mudah dipahami dan dipraktikkan.
  • Analogi: mencari kunci di kotak yang campur aduk.
  • Makin panjang daftarnya, makin lama carinya (sialnya cek semua).

Langkah Kerjanya

Mulai dari data pertama.
Bandingkan dengan target.
Jika cocok → Stop (Ketemu).
Jika beda → Geser ke data berikutnya.
Ulangi sampai data habis.

Siap mensimulasikan Linear Search.
Cara 2

Binary Search (Potong Setengah)

Cara mencari cepat dengan mengecek nilai tengah, lalu membuang setengah data yang salah.

  • Data **WAJIB sudah terurut** (misal dari A ke Z).
  • Analogi: mencari kata di kamus tebal.
  • Sangat cepat untuk data berukuran besar.
  • Fatal: Jika data acak, Binary Search akan gagal/salah.

Prinsip Kerjanya

Tentukan batas kiri dan kanan.
Cek elemen tengah (mid).
Jika target < tengah → buang bagian kanan.
Jika target > tengah → buang bagian kiri.
Ulangi pada bagian yang tersisa.

Simulasi Kelas

Cari kata PROGRAM (Binary)

Daftar terurut A-Z. Cek tengah, lalu singkirkan setengah area.

Data terurut A–Z. Siap Binary Search.
Mana yang Lebih Bagus?

Linear vs Binary

Aspek Linear Search Binary Search
Apakah data harus urut? Tidak wajib (boleh acak) Wajib terurut
Cara kerja Cek satu per satu dari awal Cek tengah, potong setengah
Mencari di data kecil Sangat praktis Biasanya tidak perlu repot urutkan
Mencari di data besar Lambat (bisa ribuan cek) Sangat cepat (1000 data cuma max 10 cek)
Analogi Mencari kunci di laci berantakan Mencari kata di Kamus cetak A-Z
