## 📱 Tips Membaca Lewat HP
1. Jika menggunakan web browser, aktifkan fitur **Desktop Site** bila tabel terasa kurang lebar.
2. Di dalam materi, jika ada tombol **Lihat Jawaban**, tekan tombol tersebut untuk melihat pembahasan latihan soal (menggunakan fitur `<details>`).
3. Untuk file `.html` interaktif (seperti slide presentasi), unduh filenya lalu buka menggunakan browser bawaan HP Anda.

## 🌐 Panduan Upload Materi Mingguan (Untuk Guru)
Materi ini diunggah secara bertahap setiap minggu sekali dengan kendali penuh dari Guru.

### Langkah-langkah update/upload materi mingguan:
1. Edit atau tambahkan materi di folder kerja utama guru: `materi ngajar kelas X Revisi/`.
2. Jalankan script sinkronisasi dari folder utama (bukan dari folder ini):
   ```bash
   python sync_to_github_repo.py
   ```
3. Buka terminal atau Git Bash di folder ini (`materi_siswa_github/`).
4. Jalankan perintah berikut untuk melihat daftar berkas yang baru atau berubah:
   ```bash
   git status
   ```
5. Tambahkan hanya berkas/folder spesifik yang ingin dirilis minggu ini (jangan gunakan git add . jika ingin membatasi akses siswa):
   ```bash
   git add <jalur/ke/nama_file.md>
   # Contoh merilis Lembar Aktivitas Minggu 1:
   git add Semester_1_Ganjil/01_Informatika_dan_Kemampuan_Umum/Lembar_Aktivitas_Minggu_1.md
   ```
6. Lakukan commit dan push berkas yang dipilih:
   ```bash
   git commit -m "Upload materi minggu ke-[Nomor_Minggu]"
   git push origin main
   ```
