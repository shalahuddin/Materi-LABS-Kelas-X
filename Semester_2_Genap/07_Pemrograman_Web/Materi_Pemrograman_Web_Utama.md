## F. Langkah-langkah Pembelajaran BERDIFERENSIASI

### Pertemuan 1: HTML dan CSS Dasar (2 JP)
1.  **Pendahuluan (15 menit):**
    *   Guru menyapa siswa dan memotivasi dengan menunjukkan halaman web menarik (misalnya, web game atau portofolio interaktif).
    *   *Pertanyaan Pemantik:* "Ketika kalian membuka Google atau Facebook, bagaimana komputer bisa tahu di mana harus menempatkan logo, tombol login, dan kotak teks? Apa bahasa yang mereka gunakan?"
    *   Guru menyampaikan tujuan pembelajaran pertemuan ini.
2.  **Kegiatan Inti (55 menit):**
    *   *Memahami:* Guru mendemonstrasikan secara langsung (*live coding*) menulis struktur dasar HTML dan menunjukkan hasilnya di browser. Menjelaskan fungsi tag `<h1>`, `<p>`, `<a>`, dan `<img>`.
    *   *Eksplorasi:* Siswa membuka browser dan menggunakan fitur "Inspect Element" (klik kanan -> Inspect) pada website favorit mereka untuk melihat struktur HTML aslinya secara visual. (Visual & Kinestetik)
    *   *Mengaplikasi:* Siswa membuka editor teks (seperti VS Code atau Codepen.io) untuk membuat file `index.html` sendiri dan menulis biodata diri singkat menggunakan tag HTML dasar.
    *   *Menghias (CSS):* Guru mengenalkan CSS. Guru memperlihatkan bagaimana mengubah warna latar belakang dan warna teks menggunakan CSS.
    *   *Praktik CSS:* Siswa menambahkan gaya CSS di dalam tag `<style>` untuk mempercantik biodata yang telah mereka buat (mengatur jenis font, warna latar, dan perataan teks).
3.  **Penutup (10 menit):**
    *   Siswa saling menunjukkan tampilan web mereka ke teman sebangku (Peer Review).
    *   Guru merangkum perbedaan peran HTML (tulang/struktur) dan CSS (kulit/tampilan).

### Pertemuan 2: JavaScript Dasar & Proyek Web Portofolio (2 JP)
1.  **Pendahuluan (15 menit):**
    *   Guru me-review materi HTML & CSS pertemuan lalu.
    *   *Pertanyaan Pemantik:* "Jika HTML membuat tombol dan CSS mewarnainya, bagaimana cara membuat tombol tersebut melakukan sesuatu saat diklik?"
    *   Guru menunjukkan demo tombol web yang mengubah warna latar belakang halaman secara acak menggunakan JavaScript.
2.  **Kegiatan Inti (55 menit):**
    *   *Memahami:* Guru menjelaskan konsep dasar JavaScript (variabel, fungsi) dan cara menghubungkannya dengan tombol HTML (`onclick`).
    *   *Praktik Terarah:* Siswa mengikuti instruksi guru untuk menambahkan JavaScript sederhana yang memunculkan pesan pemberitahuan (`alert()`) saat tombol diklik.
    *   *Proyek Mandiri:* Siswa menggabungkan HTML, CSS, dan JavaScript untuk menyelesaikan proyek **"Portofolio Pribadi"** (menggunakan draf kode dari handout detail). Siswa didorong untuk berkreasi dengan palet warna dan deskripsi diri mereka sendiri.
    *   *Debugging:* Guru berkeliling membantu siswa yang kodenya mengalami error (misalnya: salah mengetik tag penutup, lupa tanda kutip, atau salah huruf besar-kecil pada JavaScript).
3.  **Penutup (10 menit):**
    *   *Refleksi:* Siswa menjawab pertanyaan: "Apa bagian tersulit dari menulis kode web hari ini, dan bagaimana cara kalian menyelesaikannya?"
    *   Siswa menyimpan proyek web mereka dan bersiap untuk mengumpulkannya.
